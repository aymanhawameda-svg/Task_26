# Task_26

Ich habe ein browserbasiertes Escape-Game mit HTML, CSS und JavaScript entwickelt. Das Spiel umfasst drei aufeinander aufbauende Aufgaben (Zahlen-Code erraten, Passwortprüfung und eine Schleifen-Sicherheitssequenz), die logisch nacheinander freigeschaltet werden. Bei erfolgreichem Abschluss aller Level wird das System visuell entsperrt („SYSTEM UNLOCKED“).
